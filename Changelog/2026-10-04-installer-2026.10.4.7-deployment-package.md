# Installer 2026.10.4.7 — deployment-ready release package

**Date:** 2026-10-04
**Branch:** `SK-local`
**Previous release:** 2026.10.4.6

## Added
- `Build-Installer.ps1 -Version <v>` now finishes with a **deployment package**:
  - `installer\Output\Release-<v>\`
    - `RynthCore-Setup-<v>.exe` — the installer (its stamped ProductVersion must equal `<v>`).
    - `release-manifest.json` — version, release number, build time, previous release, RynthCore and
      RynthSuite branch/commit/dirty flag, every shipped component's version (launcher, engine,
      loader, Loot Editor, RynthAi, Monster Editor, experimental plugins) and the installer's size + SHA-256.
    - `RELEASE-NOTES.md` — install / silent-install / hash-verification steps, component table, and the
      Changelog entries from **both** repos added or changed since the previous release (by the previous
      manifest's commits; falls back to the previous version's build date).
    - `SHA256SUMS.txt` — `sha256sum`-format hashes of the files above.
  - `installer\Output\RynthCore-<v>-deploy.zip` — the folder zipped, then extracted to a temp folder and
    re-checked against `SHA256SUMS.txt`.
  - `installer\previous-release\last-release-manifest.json` — kept so the next release lists only new notes.
- `-AllowDirty` and `-NoPackage` switches.

## Changed
- Release (`-Version`) builds refuse uncommitted changes to tracked files in either repo (checked before the
  slow publishes) so every package maps to exact commits; `-AllowDirty` overrides and flags the manifest.
  `installer\previous-release\` is exempt because the script rewrites its markers.
- `last-built-version.txt` is written only after the whole build (including the package) succeeds, so a
  failed package step is retried rather than skipped.
- `Build-Release-All.ps1` documents the package output.

## Fixed
- **Previous-release archive mislabel:** when `RynthCore-Setup-<previous>.exe` was not in `Output\` (e.g. it
  was built in another checkout), the canonical `RynthCore-Setup.exe` — possibly an older build — was archived
  under the previous version's name. It is now archived only when its ProductVersion matches.
- **`Publish-Update.ps1` could not publish:** it copied the RynthAi plugin from `staging\plugins\RynthAi\`,
  which the full installer layout no longer creates (`staging\suite\RynthAi\`). It also now takes the
  versioned `RynthCore-Setup-<v>.exe` (the unversioned copy is best effort and may be stale).
- **False "SehTrampoline.dll is STALE" after checkouts/merges:** the check compared file times, and git rewrites
  `SehTrampoline.c` (new mtime, same content) on checkout. When the source matches HEAD its last commit
  time is used instead; local edits still use the file time.

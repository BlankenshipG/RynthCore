# RynthBundle 0.4.9 (2026-04-23)

- **Setup:** `installer\Output\RynthBundle-Setup-0.4.9.exe` (and `RynthBundle-Setup.exe` when the canonical copy succeeds).
- **Version bump:** from **0.4.8**; prior bundle archived under `installer\previous-release\`; `last-built-version.txt` -> **0.4.9**.
- **Size reduction (major):** launcher and Suite tools are now **framework-dependent** instead of self-contained:
  - `RynthCore.App.Avalonia` published `win-x86 --self-contained false`
  - `RynthCore.LootEditor` and `RynthCore.MonsterEditor` published `win-x64 --self-contained false`
- **Runtime link only (no bundled download):** installer now includes a Start Menu shortcut to the official .NET runtime page and ships `RynthCore-Prerequisites.txt` in the install root with direct runtime guidance.
- **Build:** `Build-Release-All.ps1 -Version 0.4.9` from the RynthCore repo root.

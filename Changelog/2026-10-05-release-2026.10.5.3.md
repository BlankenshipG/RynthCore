# Release 2026.10.5.3: ILT Hub windows, Char/Hub buttons, logging warning

**Date:** 2026-10-05
**Installer:** `RynthCore-Setup-2026.10.5.3.exe` (previous release: 2026.10.5.2)
**Sources:** RynthCore `merge/aelrynth-2026.10.5.1`; RynthSuite `merge/aelrynth-2026.10.5.1` (532fa67, unchanged)

## Summary

A second test build of the aelrynth 2026.10.5.1 merge, fixing what 2026.10.5.2 got wrong in game.
Details: `2026-10-05-ilt-hub-context-char-hub-logging.md`.

## Fixes

- **ILT Hub and RynthAi's other ImGui windows** (Mini Remote, Inventory HUDs, Item Info,
  translator, nav overlay) draw again. Plugins now get the engine's ImGui context when plugin
  overlay windows are enabled. **UbRythai** starts again too; it refuses to start without that context.
- **Char and Hub buttons** are back on the in-game RynthAi dashboard (the ImGui one):
  - Char opens the ILT Hub.
  - Hub: left-click toggles the Mini Remote; right-click opens the Inventory HUDs setup.
- **Logging:**
  - The engine's startup banner is always written.
  - A warning names any log category set above the global LoggingLevel; those categories
    are not logged at all.

## Still open

- No Decal bridge in this build (Decal 3.0 is not installed on the build machine).
- Several new upstream paths are hard-coded to `C:\Games\...`.
- The ImGui Items view has no Shields section yet.
- RynthAi's 0.6.33 augmentation clamp fix is still stashed on SK-local.

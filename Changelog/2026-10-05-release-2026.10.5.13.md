## Included changes

- **SK fixes the aelrynth merge dropped are back:**
  - the pet essence refill loop guard;
  - AutoStack reading the engine's merge-stack result;
  - data files under the install folder instead of `C:\Games\RynthSuite`;
  - per-category logging in Jumper, Salvage and Raycasting.
- **Settings panel:**
  - "Loot Items On Ground" (Looting).
  - Item Info "Describe Items When Selected" and an options button (Display).
  - A new Diagnostics tab: debug to chat, daily log file, log folder / prune, and a per-category trace grid.
- **Nav panel route editor:**
  - Multi-select (Ctrl/Shift), double-click to set active, right-click menu, Delete key.
  - Up / Down / Duplicate / Delete / Set Active / Move Here.
  - Nearest, Reverse, Snap to Path, Point at Selected, Add Pause, Simplify.
  - Add Portal (selected object).
  - Record route.
  - Route from Trail / Backtrack.
- **RynthAi's unused plugin-drawn window code was removed.** It had no visible effect.

See `2026-10-05-rynthai-0.5.15-restore-sk-features.md`.

## What to check in game

- `/ra version` reports `0.5.15-legacy-ui`.
- **Nav panel:**
  - Ctrl-select three waypoints and click Up; they move and stay selected.
  - Right-click a row and choose Set Active; the `=>` marker moves.
  - Select a portal and click Add Portal; a Portal step with the portal's name is added.
  - With Breadcrumbs on, walk a while, then Route from Trail > backtrack; an unsaved route that walks back appears.
- **Settings > Diagnostics:** "ILT Hub on" ticks the IltHub categories; `/ra trace` lists them.
- **Settings > Looting:** toggling "Loot Items On Ground" survives a relog.

# RynthCore engine 2026.10.5.17 — Progression tab laid out like UB's ILT Tools XP and Augs tabs

**Date:** 2026-10-07
**Previous release:** 2026.10.5.16 (main integration)
**Branch:** `QOL-items`
**Pairs with:** RynthAi 0.5.23-legacy-ui, which sends the new snapshot fields. With an older
RynthAi the panel falls back to plain +1 / +10 buttons and the old totals lines.

## Attribute raiser (`ImGui/Panels/SkillsFace.Progression.cs`)

- The table now has UB's columns: **Auto** (tick), **Stat**, **Base**, **+1 Level**, **+10
  Levels** and **Order** (arrows).
- The raise buttons fill their cells and are labelled with what they cost: the next-level cost
  from `/xp all`, and `~` plus the projected cost for ten levels.
  - Teal with a teal border: you can afford it.
  - Red and disabled: the known cost is more than your unassigned XP.
  - Plain: the cost hasn't been read yet. The button still works and the server decides.
  - Tooltips give the exact XP and why a button is off.
- The header shows "Level N   Total XP X   Unassigned Y".
- "Refresh costs" is now "Refresh XP", with "Last updated: HH:mm:ss" beside it.
- The footnote explains that +10 is a 7.7%-per-level estimate.

## Augmentations

- Four buttons, as in UB's Augs tab:
  - **Refresh current** reads your levels with `/aug`. RynthAi also does this once when the tab
    first opens.
  - **Reset targets** sets every target back to the current level.
  - **Copy Discord** and **Copy in-game** put RynthAi's ready-made text on the clipboard with
    `ImGui.SetClipboardText`.
- The table now has **Current / Target / Inc / Luminance / Coins** columns and a **TOTALS** row.
- **Target** has −/+ step buttons (Ctrl for 100). Typing commits on Enter or when the box loses
  focus, so a half-typed number is never sent. It is clamped to current..cap before sending.
- **Lum per e-coin** also commits on Enter or focus loss (it used to send on every keystroke) and
  accepts k / m / b / t.
- Under the table: E-coins needed / banked / short, the luminance needed to buy them, and your
  banked luminance.

## Data (`UI/Data/ProgressionData.cs`)

- `AttrRaiser`: `Updated`, `XpHeader`.
- `AttrRow`: `Known`, `Afford1`, `Afford10`, `Cost10`, `CostFull`, `Cost10Full`.
- `AugPlanner`: `TotalCurrent`, `TotalTarget`, `TotalIncrease`, `TotalLum`, `TotalCoins`,
  `CoinsLine`, `LumToBuy`, `CopyDiscord`, `CopyIngame`.
- `AugRow`: `Increase`.
- Every new field has a default, so an older RynthAi's snapshot still deserializes.

## Build

- `scripts/Publish-EngineCoreClr.ps1 -Target out\staged-2026.10.5.17 -EngineOnly -MsBuildArgs
  @('-p:Version=2026.10.5.17')`. It built with no errors; the one warning (CS0618 in
  `EntryPoint.cs`) was already there.
- `RynthCore.Engine.dll` FileVersion 2026.10.5.17.
- Not deployed. Called with no `-Target`, the script deploys to the live Runtime, and its
  status-export check refused this checkout.
- This is a `QOL-items` engine (plugin API 80). Deploy it only together with a RynthAi built
  against the `QOL-items` SDK, such as RynthAi 0.5.23.

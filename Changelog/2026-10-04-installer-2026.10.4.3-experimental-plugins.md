# RynthCore 2026.10.4.3: experimental plugins as optional installer components

**Release date:** 2026-10-04
**Installer:** `installer\Output\RynthCore-Setup-2026.10.4.3.exe` (also copied to `RynthCore-Setup.exe`)
**Previous release:** `2026.10.4.2` (archived to `installer\previous-release\RynthCore-Setup-2026.10.4.2.exe`)
**Branch:** `feat/full-installer` (local test build, not on `main`)

## What's new

The **Select Components** page has a new **RynthSuite: Experimental plugins** group. Each plugin is unchecked by
default in every install type; ticking one switches the install to Custom.

| Component | Installs to | Version |
|---|---|---|
| `experimental\rynthchat` | `<RynthSuite>\RynthChat\RynthCore.Plugin.RynthChat.dll` | 0.1.1 |
| `experimental\rynthjuice` | `<RynthSuite>\RynthJuice\RynthCore.Plugin.RynthJuice.dll` | 0.1.1 |
| `experimental\rynthnav` | `<RynthSuite>\RynthNav\RynthCore.Plugin.RynthNav.dll`, plus `<RynthCore>\NavData\` | 0.5.5 |
| `experimental\rynthtracker` | `<RynthSuite>\RynthTracker\RynthCore.Plugin.RynthTracker.dll` | 0.1.1 |
| `experimental\rynthvision` | `<RynthSuite>\RynthVision\RynthCore.Plugin.RynthVision.dll` | 0.1.1 |

- **Registration:** every selected plugin (RynthAi included) goes into `Software\Rynth\PendingPluginRegistration`
  as a `;`-separated list. On next start the launcher adds them all to its Plugins list and syncs `engine.json`.
- **Suite folder page:** shown whenever any RynthSuite component is selected, experimental ones included.
- **RynthNav data:** the installer creates `<RynthCore>\NavData` (kept on uninstall). It ships the starter
  `portals.tsv` from `RynthNav.PortalGraph` only when that folder has none, so a newer generated file is never overwritten.
  Navmesh tiles (`nav_XXXX.tile`) are **not** shipped; bake them with `RynthNav.Baker --tiled` (its default output
  is `C:\Games\RynthCore\NavData`; pass `--out` for a different RynthCore folder).
- **Silent installs:** pick components with `/COMPONENTS`, for example
  `/COMPONENTS="core,rynthai,monstereditor,experimental\rynthnav,experimental\rynthvision"`.

## Build script (`installer\Build-Installer.ps1`)
- New step **7/7** publishes the five plugins (NativeAOT, x86), each keeping its own version.
- RynthJuice, RynthNav and RynthVision set `<PublishDir>` to the live `C:\Games\RynthSuite\<Name>\` for dev hot-reload.
  The build overrides it to each project's `bin\...\publish\`, so building an installer never touches a live install.
- Staging: `staging\suite\<Name>\` per plugin and `staging\navdata\portals.tsv`. All of them are in the required-files check.

## Upgrade notes
- Re-running the installer without an experimental plugin does not remove one installed earlier. Uninstall
  RynthCore, or delete `<RynthSuite>\<Name>\` and its row in the launcher's Plugins tab.
- These plugins are work in progress and may change or break between builds.

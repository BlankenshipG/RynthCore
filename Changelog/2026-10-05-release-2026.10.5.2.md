# Release 2026.10.5.2: first build on the aelrynth 2026.10.5.1 merge

**Date:** 2026-10-05
**Installer:** `RynthCore-Setup-2026.10.5.2.exe` (previous release: 2026.10.4.22)
**Sources:** RynthCore `merge/aelrynth-2026.10.5.1`; RynthSuite `merge/aelrynth-2026.10.5.1` (532fa67)

## Summary

The first installer built from the merge of upstream aelrynth 2026.10.5.1 with SK-local.
The version sorts above upstream's 2026.10.5.1, so the launcher's updater sees it as newer.
This is a test build of the merge: it has not been tested in game yet.

## What's in it

- **Engine:** upstream's unloadable CoreCLR engine, hosted by the native loader, with an
  app-local .NET 10 runtime in `Runtime\dotnet`. This is the installer's new default;
  the previous NativeAOT engine is still available via `Build-Installer.ps1 -NativeAot`.
- **Plugin API v77:** the RynthAi in this installer is built against it. Do not use an
  older SK-local RynthAi (0.6.32 or earlier) with this engine. It reads the
  merge-stack-result entry from a slot that upstream now uses for something else.
- **RynthAi:** the upstream plugin with the SK-local features wired on (ILT Hub, HUDs,
  translation, item info, ground loot, nav overlay). It reports `0.5.1-legacy-ui`.
- **Upstream features and SK-local ports:** see
  `2026-10-05-aelrynth-2026.10.5.1-merge.md` for the full list.
- **Decal bridge:** not included in this build (Decal 3.0 is not installed on the build
  machine). "Decal + RynthCore" accounts can't run from this installer.

## Known gaps

- Several new upstream paths are hard-coded to `C:\Games\...`. Installs in other folders
  may log or save to the wrong place.
- The ImGui Items view has no Shields section yet; the Avalonia Items panel has one.
- RynthAi's 0.6.33 augmentation clamp fix is still stashed on SK-local and is not in this build.

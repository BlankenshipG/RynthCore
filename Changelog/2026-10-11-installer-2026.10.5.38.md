# Full installer 2026.10.5.38

Full installer `RynthCore-Setup-2026.10.5.38.exe` (previous full installer: 2026.10.5.37). It is
built with `installer\Build-Installer.ps1 -Version 2026.10.5.38` from branch `build-comp-10-11` in
both repos.

## What it ships

- Everything in 2026.10.5.37 (see `2026-10-11-installer-2026.10.5.37.md`): the Mini Remote merge,
  universal Quests and Pets, Character / Server menus, shared tracker logic, closest-waypoint
  navigation, Items: Remove Missing, recall on death, inventory multi-select and attribute
  filter, Charms in the ILT Mini Remote, ACECustom banking, and RynthJuice and UbRythai.
- New since 2026.10.5.37:
  - Game-tick crash guard: a native fault inside AC's `Client::UseTime` (the `chatclient.dll`
    null read that took down two clients at 23:22) drops one tick instead of ending the client.
    RynthCore.SehTrampoline.dll v4. See `2026-10-11-gametick-chatclient-guard.md`.
  - `Publish-EngineCoreClr.ps1` moves a locked trampoline aside so new launches get the new one.
  - RynthAi 0.5.46-legacy-ui: `fix/loot-merge-pacing` (24f3c4f), corpses with several
    stackable keeps are looted to the end (RynthSuite
    `Changelog/2026-10-11-release-0.5.46-loot-merge-pacing.md`).
- The engine, launcher and tools are stamped 2026.10.5.38, the same engine code as the installed
  2026.10.5.38.

## Output

- `installer\Output\RynthCore-Setup-2026.10.5.38.exe`, plus a `RynthCore-Setup.exe` copy.
- The deployment package `installer\Output\Release-2026.10.5.38\` and
  `RynthCore-2026.10.5.38-deploy.zip`, containing SHA256SUMS, the release manifest and
  RELEASE-NOTES.
- The previous installer (2026.10.5.37) is archived in `installer\previous-release\`.

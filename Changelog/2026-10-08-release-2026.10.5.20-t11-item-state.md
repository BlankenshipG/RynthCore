# RynthCore engine 2026.10.5.20 - Add-to-loot text for the new T11 item state

**Date:** 2026-10-08
**Previous release:** 2026.10.5.18 (2026.10.5.19 is reserved by the Skills augments-tab work on
`feat/skills-augments-tab`, not yet released)
**Branch:** `QOL-items`
**Pairs with:** RynthAi 0.5.26-legacy-ui

## Why

RynthAi 0.5.26 reads the T11 state ACECustom added in its endgame updates: the stamped loot tier
(`ZcTier` 50109, `WeaponAugScaleTier` 9061), the weapon quality roll (`WeaponAugScaleQuality` 9060),
Gear Grade, property slots, Tainted and the jewelry Cast on Strike. "Add to loot profile" with
"Include T11 attributes" now adds the stamped tier and Gear Grade, so the checkbox tooltip had to say so.

## What changed

- `ImGui/Panels/LootAddDialog.cs`: the "Include T11 attributes" tooltip lists the server's stamped tier,
  gear grade, and that property slots / Tainted are not added.
- No engine-side key tables changed: the new loot keys (T11: Gear Grade, Tier Is Exact, Property
  Slots, Tainted, T11 Mod: Cast on Strike, and the named ZcTier / WeaponAugScale* properties) and the
  Gear Grade letter table come from RynthAi's editor vocabulary, so the loot editor face shows them
  as soon as RynthAi 0.5.26 is loaded.

## Build

- `scripts/Publish-EngineCoreClr.ps1 -EngineOnly -MsBuildArgs @('-p:Version=2026.10.5.20')`
- Previous live engine saved to `C:\Games\RynthCore\PreviousReleases\2026.10.5.18-engine\`.

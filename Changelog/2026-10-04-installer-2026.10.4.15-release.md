## Changes

- **Engine fix: plugin ImGui windows now draw.** The plugin render snapshot was never
  published after plugins loaded, so `RenderAll` / `RenderOverlayAll` called no plugins
  and windows such as the RynthAi ILT Hub never appeared. See
  `2026-10-04-plugin-render-snapshot-fix-and-imgui-diagnostics.md`.
- **Engine diagnostics:** one-time Info lines for the ImGui gate, init, first frame, branch,
  first draw submit and overlay plugin binding, plus a 30 s heartbeat. Repeated frame
  exceptions are rate-limited.
- CS0162 (unreachable code) is now a build error in the engine.

## Upgrade notes

- No plugin API change (still v69); plugins do not need rebuilding.
- `engine.json` may still be at `Trace` from earlier debugging. Set the logging level back to
  `Info` in the launcher once the Hub is confirmed working.

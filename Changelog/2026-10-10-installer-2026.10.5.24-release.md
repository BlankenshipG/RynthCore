## Contents

- **Engine 2026.10.5.24** (same code as the live 2026.10.5.23, now stamped with the installer
  version):
  - 2026.10.5.23: large-address alignment fix. On a large-address-aware client the 190
    `and r32,0x80000003` sites in AC's unpack code rounded heap blocks above 2 GB to the wrong
    size and crashed in open world. The engine now patches them in memory at load
    (`2026-10-10-release-2026.10.5.23-large-address-alignment-fix.md`).
  - 2026.10.5.22: Buffs picker under Loaded Files and the Spells window button.
- **HookResolver UI 1.0.1:** Tmds.DBus.Protocol pinned to 0.21.3 (GHSA-xrw6-gwf8-vvr9). It is a
  developer tool and is not in the installer; listed because its changelog falls in this range.
- **RynthAi 0.5.32-legacy-ui:**
  - 0.5.32: Mini Remote / ILT Hub Lum/h follows the bank's luminance property, so
    fellowship and zone-share luminance count.
  - 0.5.25 (first shipped here): enlightenment planner breaks levels 301-325 down into the
    sigil craft chain (crafts left, raw items, e-coin demand).
  - 0.5.28 - 0.5.31: Mini Remote drawer without Toggles, item info kept on profile load,
    Bounties window, Spells window and buff profiles.

# RynthAi 0.5.15-legacy-ui: SK features restored after the aelrynth merge

**Date:** 2026-10-05
**Components:**
- RynthSuite: RynthAi plugin (`Plugins/RynthCore.Plugin.RynthAi`) and host tests. Branch `fix/restore-sk-features`.
- RynthCore: engine (`src/RynthCore.Engine`). Branch `fix/restore-sk-features`.

**Previous release:** 0.5.14-legacy-ui

## Background

The aelrynth merge (e11692b) resolved many RynthAi files wholesale to the aelrynth side. That dropped several SK changes. It also stopped RynthAi from drawing its own ImGui windows (Advanced Settings, Navigation, Macro Rules, Monsters), whose options now live in the engine panels.

This release:
- re-merges the lost SK fixes;
- ports the two SK window features the engine panels lacked (Settings options and the Navigation route editor);
- deletes the window code nothing draws any more.

## Restored fixes (RynthSuite)

- **Pet essence refill loop guard** (c1a1ee6), dropped by the merge.
- **SK sides of wholesale-resolved files** (35a895e), re-merged against the shared 2026.9.27.3 snapshot:
  - `InventoryManager`: AutoStack reads the engine's merge-stack result instead of re-sending merges blindly.
  - `DungeonHazardStore`/`DungeonHazardSurfaces`, `MetaManager`, `RadarWallRenderer`: data files resolve under `RynthInstallPaths.RynthAiDir` instead of `C:\Games\RynthSuite`.
  - `Jumper`, `SalvageManager`, Raycasting: per-category `RynthLog` output.
  - `NavCoordinateHelper.TryGetNavPosition` (NS/EW plus nav-unit Z), used by the route editor.

## Settings (engine Settings panel)

The plugin's settings bridge payload carries these new fields: `EnableGroundLoot`, `ItemInfoOnSelect`, `DiagDebugToChat`, `DiagFileLogAll`, `DiagCategories` (`Name=Level,...`) and the read-only `DiagFolder`. Fields missing from a save keep their current values.

- **Display > Item Info:**
  - "Describe Items When Selected" (`/ra iteminfo on|off`).
  - "Item Info Options" opens the item info window.
- **Looting:** "Loot Items On Ground".
- **New Diagnostics tab:**
  - Debug to chat.
  - Daily RynthAi log file.
  - Log folder [Open] and old log files [Prune].
  - "Trace Per Category": a toggle grid with All on / All off / ILT Hub on. A category set to Info keeps Info when toggled.
- **Plugin side:**
  - `RynthLog.FormatCategoryLevels`/`ApplyCategoryLevels`.
  - Remote commands `trace`, `logs` and `iteminfo`.
- Both the ImGui `SettingsFace` and the Avalonia `SettingsPanel` render the trace grid.

## Navigation route editor (engine Nav panel, ImGui face)

SK's route editing returns as nav bridge commands, which the plugin handles in `LegacyDashboardRenderer.NavEdit.cs`. Structural edits go through `NavRouteEditing.Apply` (copy-on-write), so navigation never sees a half-edited route.

- **Selection:**
  - Click selects a row; Ctrl-click toggles a row; Shift-click selects a range.
  - Double-click sets the active waypoint.
  - Right-click opens a row menu.
  - Delete removes the selected rows.
- **Edit row:** Up, Down, Duplicate (the copies end up selected), Delete, Set Active, Move Here.
- **Tools row:**
  - Nearest and Reverse.
  - Snap to Path: inserts a point at the spot on the route closest to you (refused when that spot is already a waypoint).
  - Point at Selected.
  - Add Pause: 1 to 60 s presets.
  - Simplify: 0.5 to 5 yd tolerance presets.
- **Add Portal** is enabled. It adds a Portal step for the selected object, with its position as the exit.
- **Record route** toggle (`/ra navrec`).
- **Route from Trail...:** replaces the route with the breadcrumb trail or its backtrack. The new route is unsaved; the loaded nav file is unchanged.
- **Status line:** the last edit's result shows for 8 s (for example "Simplify (1 yd) removed 4 point(s).").
- **Bridge fields:**
  - Payload: `IsRecording`, `TrailPoints`, `TrailYards`, `EditStatus`.
  - Commands: `Indices`, `Delta`, `Seconds`, `Yards`, `Reverse`.
- The face remaps its selection locally the same way the plugin edits the route, so rows stay selected after a move, duplicate or reverse.
- The Avalonia Nav panel is unchanged.

## Removed: plugin-drawn window code (RynthSuite)

- **Deleted** (no callers): `LegacyAdvancedSettingsUi`, `LegacyMonstersUi`, `LegacyDashboardDrawing`, `ExternalTool`, `SuiteToolPaths`, and the already-excluded `LegacuLuaUi.cs` (702e813).
- **`LegacyNavigationUi`** keeps `SaveRoute`, `TryAutoSaveNav` and `IndexAfterDelete`.
- **`LegacyMetaUi`** keeps `LoadMacroFile` and its status/warnings.
- **Dashboard:**
  - Missile-crafting state moved into the dashboard.
  - The unused Monster Editor launcher and its Win32 plumbing were removed.
  - The AutoVendor/AutoTrade status providers were removed; only the deleted window read them.
- **Settings:** removed `ShowAdvancedWindow`, `SelectedAdvancedTab`, `AdvancedTabs`, the `DashShow*` flags and the matching `DashWindows` fields. Old settings files still load; unknown JSON keys are skipped.

## Tests

`RynthCore.RynthAiHostTests`: since 35a895e, `SalvageManager` logs through `RynthLog`, so five salvage tests no longer saw their `[Salvage]` lines. The salvage test world now binds `RynthLog` to its fake host, with a temp diagnostics folder.

Result: 361 tests, 356 passed, 0 failed, 5 known failures (unchanged).

## Not restored

- **Larger SK logic changes** in `CombatManager`, `WorldObjectCache`, `QuestTracker`, `BuffManager` and others, where aelrynth's versions replaced SK's.
- **Shields, ammo and ground loot logic:** aelrynth's implementations were kept.
- **Engine-owned options** (radar, chat, dungeon map) and the gaps not selected: dashboard extras, VT `.utl` import, profile folder picker, Monster Editor button.

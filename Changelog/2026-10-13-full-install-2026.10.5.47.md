# Full install build 2026.10.5.47 (local)

Local full installer plus a local deploy of the feed plugins, built from the checkouts on this
machine after they were synced with upstream release 2026.10.13.2. Not published upstream.

Previous installer: 2026.10.5.46 (archived in `installer\previous-release\`).

that is in sync with upstream. Built without `-AllowDirty`: the manifest maps to exact commits.

## What's new over 2026.10.5.46

- Everything in upstream 2026.10.13.1 and 2026.10.13.2, including the RynthILT split: the ILT Hub
  (progression, augmentations, enlightenment) now lives in the RynthILT plugin instead of RynthAi.
- Plugin API v84: confirmation answers (craft-chance prompt) for plugins.
- The aug "Refresh current" fix and the single Attributes section, now in RynthILT.
- Crafting tab in the RynthAi Mini Remote (tinkering, trinkets, Rings chain, auto next batch).
- Environment-hit throttle, attack power modes, mixed-launcher swaps, pet damage-type colours.
- Security review fixes: SafeImGui for '%' in shown text, chat-origin checks so player chat
  can't fake server replies, combat lines or the vault feed, StatusAgent hardening.
- RynthLua: `string.format` no longer dies on a nil argument.

## Notes

- The installer does not carry RynthILT, RynthInventory or RynthLua: upstream ships those
  through the launcher's plugin feed. Their local builds are copied into
  `C:\Games\RynthSuite\<plugin>` after the install, with the old DLLs kept as `.previous`.
- The launcher will show "RynthCore 2026.10.13.2 is available", because 2026.10.5.47 is a
  lower release number. Don't take that update while testing: it replaces this build.
- No Decal bridge: Decal 3.0 isn't installed on this machine.
- Commands: `dotnet build RynthCore.sln -c Release`, then
  `installer\Build-Installer.ps1 -Version 2026.10.5.47`.

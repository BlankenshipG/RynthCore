## Summary

The sixth test build of the aelrynth 2026.10.5.1 merge. Nothing has been tested in game.
Details: `2026-10-05-rynthai-cimgui-binding.md`.

## Fixes

- **RynthAi's own windows draw again.** This covers the Mini Remote, Pets, Quests, ILT Hub, Item HUD
  and Inventory HUDs.
  - Cause: since the merge, the engine loads `RynthCore.cimgui.dll`, so RynthAi's ImGui calls went to
    a second `cimgui.dll` that the engine never draws.
  - Fix: RynthAi now binds to the engine's module, as ub-Rythai does. The RynthAi UI log should show
    `[ImGui] cimgui bound to loaded RynthCore.cimgui.dll`.
- **Two clients no longer overwrite each other's RynthAi logs.** The second client writes
  `{name}.{pid}.txt` beside the first client's file.

## Build notes

- Only the usual warnings: Decal isn't installed on the build machine, so there's no Decal bridge;
  and CS0618 in `EntryPoint.cs`.

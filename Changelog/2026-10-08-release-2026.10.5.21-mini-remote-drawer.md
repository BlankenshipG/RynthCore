# RynthCore 2026.10.5.21: Mini Remote drawer on the RynthAi dashboard

Released 2026-10-08. Previous release: 2026.10.5.20 (T11 item state tooltip).
Pairs with RynthAi 0.5.27-legacy-ui.

## What's new

- **Mini Remote drawer.** The RynthAi dashboard has a fourth left-edge drawer,
  under Ranges, Loaded files and Patrol. It holds RynthAi's whole Mini Remote:
  - session rates with Reset XP / Report
  - the attack target and summon health bars, with the summon's time left
  - the 5 x 6 item slots (click to use, right-click to assign, drag items in)
  - the macro toggles, bank balances and rebuff buttons
  - the Translate row and the Guardian answer
- **Options inside the drawer.** The remote's Options button, or a right-click on
  it, opens the same menu as the floating window: which sections show, the ILT Hub
  windows, horizontal layout, Inventory HUDs setup, and "Floating window too".
- **Opening it.** Use the drawer tab, or right-click the **Hub** launcher (as
  right-clicking Patrol opens its drawer). Left-click Hub still toggles the floating
  Mini Remote. On a popped-out dashboard (no drawers), right-click Hub shows the
  floating Mini Remote.
- The drawer sizes itself to the remote: one column when stacked, three side by side
  in horizontal layout. It is never taller than the screen; past that it scrolls.
- The drawer's open / closed state is saved with the dashboard, as line 11 of
  `rynthai_avalonia.cache`.

## Changed

- Right-click **Hub** no longer opens Inventory HUDs setup directly. It is in the
  Mini Remote's Options menu (and `/ra huds`).

## Plugin API

- New optional plugin export:
  `int RynthPluginRenderEmbed(const char* surface, float width, float height, float* wantWidth, float* wantHeight)`
  (Cdecl).
  - The engine calls it on the render thread, inside a child window of the size
    given, in the main ImGui context.
  - The plugin draws the named UTF-8 surface there and reports the content size it
    wants.
  - Returns 1 if it drew, 0 if it isn't ready or doesn't know the surface.
- The export is resolved at load, like `RynthPluginRenderOverlay`.
  - A plugin without it shows a "needs RynthAi 0.5.27 or later" note in the drawer.
  - If it throws, the export is switched off for the session; the plugin keeps
    running.
- No `RynthCoreAPI` struct change; the API version is unchanged.

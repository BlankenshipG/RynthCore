## Changes

- **Looting fix: name rules never matched** (RynthAi 0.6.27). Loot rules that match on item name
  read an empty string, because ACE never sends `Name` in appraisal data and the evaluator runs
  off the main thread. Every corpse item was left behind; SilentKelpie looted nothing across 225
  items. Name reads now fall back to the object's snapshot name. See
  `2026-10-04-loot-name-rules-and-ground-loot.md`.
- **Loot items on the ground** (RynthAi 0.6.27). A port of UB-IT AutoGroundLoot: loose ground
  items that match the active loot profile are picked up within the corpse max range. Corpses
  are looted first. Turn it on in Advanced Settings > Looting > **Loot Items On Ground** or with
  `/ra groundloot on|off|status|scan`.

## Upgrade notes

- No engine or plugin API change. Ground loot is off by default.
- `engine.json` may still be at `Trace` from earlier debugging; set it back to `Info` in the launcher.

## Changes

- **Missile ammo detection** (RynthAi 0.6.24). Ammo already in the ammo slot is recognised even
  when its name isn't a stock arrow/bolt/dart name: it is matched by equip slot, `CombatUse` and
  `AmmoType`, with a fallback probe and an `[AmmoDiag]` log line. See
  `2026-10-04-missile-ammo-detection.md`.
- **Char / Hub launcher buttons** (RynthAi 0.6.25). "ILT Hub" is now **Char**, and a new **Hub**
  button toggles the Mini Remote (right-click in the Avalonia panel opens Inventory HUDs). See
  `2026-10-04-char-and-hub-launcher-buttons.md`.
- **Pet scan by type** (RynthAi 0.6.26 + engine). The ILT Hub Pet tab and Scan pack only count
  real pet devices (essence WCID block, summoning-gem icon underlay, Summoning use requirement,
  ACECustom bond/potency). A name ending in "Essence" is no longer enough. The engine now serves
  `IconOverlay` / `IconUnderlay` DIDs. See `2026-10-04-pet-scan-type-detection.md`.

## Upgrade notes

- No plugin API version change. `IconOverlay` / `IconUnderlay` reads return false on older
  engines, and RynthAi then confirms pets from appraisal data instead.
- `engine.json` may still be at `Trace` from earlier debugging; set it back to `Info` in the launcher.

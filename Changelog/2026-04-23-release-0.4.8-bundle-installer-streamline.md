# RynthBundle 0.4.8 (2026-04-23)

- **Setup:** `installer\Output\RynthBundle-Setup-0.4.8.exe` (and `RynthBundle-Setup.exe` when the canonical copy succeeds).
- **Version bump:** from **0.4.7**; prior bundle archived under `installer\previous-release\` when `-Version` differs; `last-built-version.txt` → **0.4.8**.
- **Installer streamlining:**
  - Removed the duplicate **`Suite\RynthAi\RynthCore.Plugin.RynthAi.dll`** mirror; the plugin ships only under **`Runtime\Plugins\`**. User data and optional manual DLL copies remain under **`C:\Games\RynthSuite\RynthAi\`** (`[Dirs]` in `RynthCore.iss`).
  - **Engine `cimgui`:** one shipped native next to `RynthCore.Engine.dll` — **`RynthCore.cimgui.dll`** only. MSBuild copies the prefixed name, then deletes redundant **`cimgui.dll`** / **`Native\*.cimgui*`** drops from ImGui.NET / ILC so the publish folder is not bloated.
- **Build:** `Build-Release-All.ps1 -Version 0.4.8` from the RynthCore repo root.

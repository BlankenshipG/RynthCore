**RynthAi:** 0.5.4-legacy-ui

## Summary

The fourth test build of the aelrynth 2026.10.5.1 merge. Nothing has been tested in game.

## Fixes

- **ImGui windows draw on top of Avalonia panels.** The ImGui frame is still built in
  `EndScene`, but its draw data is now submitted after `OverlayTextureRenderer.Render`. Before
  this, the ILT Hub and other ImGui windows could be hidden behind a docked Avalonia panel. Mouse
  priority over ImGui windows (`Win32Backend.ImGuiOwnsMouseOverAvalonia`) survived the merge
  unchanged. Details: `2026-10-05-imgui-over-avalonia-port.md`.

## Features

- **Inventory panel > right-click > "Add to item count HUD"** adds the item (by name) to the
  floating item count HUD and shows it. Typed equivalent: `/ra itemhud add <name>`. Details:
  `2026-10-05-inventory-add-to-item-count-hud.md`.
- **Char panel rework**. Details: `2026-10-05-char-panel-rework-progression-pets-quests.md`.
  - The Skills panel has a Progression tab (ILT worlds) with:
    - an exact XP planner;
    - the Augmentation and Enlightenment planners.
  - Pets has its own window (`/ra pets`). The Quests window (`/ra quests window`) now includes
    Quest bonus.
  - ILT Hub tabs: Character (Session rates), Quests, Pet, Banking, Gear, Games.
  - Char launcher right-click menu: ILT Hub, Pets window, Quests window, Progression.

## Build notes

- Only the usual warnings: Decal isn't installed on the build machine, so there's no Decal bridge;
  and CS0618 in `EntryPoint.cs`.

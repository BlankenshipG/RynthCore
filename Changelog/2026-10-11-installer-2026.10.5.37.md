# Full installer 2026.10.5.37

Full installer `RynthCore-Setup-2026.10.5.37.exe` (previous full installer: 2026.10.5.26). It is
built with `installer\Build-Installer.ps1 -Version 2026.10.5.37`.

## What it ships

- Everything since 2026.10.5.26, which until now only went out as engine-only updates
  (2026.10.5.27 to 2026.10.5.36). See the other 2026-10-11 Changelog entries for details:
  - the Mini Remote merge (ILT Hub and Infinite Bounties under one window), universal Quests and
    Pets tabs, and Character / Server menus;
  - tracker and Mini Remote using the same luminance and XP logic;
  - Navigation: go to the closest waypoint;
  - Items: Remove Missing;
  - On Death: recall with a spell or an item;
  - inventory multi-select and the inventory attribute filter;
  - the Charms tab moved into the ILT Mini Remote;
  - Banking updated to ACECustom's current `/bank` (Prestige Coins, deposit, withdraw).
- RynthAi 0.5.45-legacy-ui. The engine, launcher and tools are stamped 2026.10.5.37. Apart from
  the version number, the engine is the same code as the installed 2026.10.5.36.

## Output

- `installer\Output\RynthCore-Setup-2026.10.5.37.exe`, plus a `RynthCore-Setup.exe` copy.
- The deployment package `installer\Output\Release-2026.10.5.37\` and
  `RynthCore-2026.10.5.37-deploy.zip`, containing SHA256SUMS, the release manifest and
  RELEASE-NOTES.
- The previous installer is archived in `installer\previous-release\`.

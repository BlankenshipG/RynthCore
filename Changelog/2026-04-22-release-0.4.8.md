# Release notes — RynthBundle **0.4.8** (2026-04-22)

## Installer

- **Primary output:** `installer\Output\RynthBundle-Setup-0.4.8.exe` (Inno **`OutputBaseFilename`** is versioned when **`-Version 0.4.8`** is passed to **`Build-Installer.ps1`**).
- **App version (Inno Setup):** `0.4.8`.
- **Pipeline:** launcher self-contained x86 (with **`RollForward=Disable`** on publish), engine NativeAOT x86, injector self-contained x86, **RynthSuite** `Plugins\RynthCore.Plugin.*`, **ub-Rythai** when present, LootEditor + MonsterEditor x64, staging, Inno Setup.

## Highlights in this bundle

- **.NET 10+ prerequisite (Loot/Monster tools):** `RynthCore.iss` also accepts **`HKLM\SOFTWARE\dotnet\Setup\InstalledVersions\x64\sharedhost`** (and the parallel **`SOFTWARE\Microsoft\dotnet\Setup\...`** key) when **`Version`** is **10+**. See `Changelog/2026-04-22-installer-prereq-sharedhost-and-bundled-runtime-fallback.md`.
- **Launcher / injector publish:** `Build-Installer.ps1` passes **`-p:SelfContained=true -p:PublishSelfContained=true -p:RollForward=Disable`** for the bundled apphosts.
- **Launcher assembly:** `RynthCore.App.Avalonia` **0.1.2** (Informational: `0.1.2-scd-rollforward-disable`).

# Settings > Game Client: VirindiTank import (2026.11.22.42)

Previous engine tip: 2026.11.22.40.

## Change

Game Client gains a **VirindiTank** section with **Import…**. It runs `/ra vtimport` through
RynthAi (confirm first). Available on every server — the import UI is no longer only on the ILT
Hub / Mini Remote Gear tab.

RynthAi copies VirindiTank loot, nav maps and metas into LootProfiles / NavProfiles / MetaFiles and
merges MyMonsters from text `.usd` (see RynthSuite changelog for 0.5.100).

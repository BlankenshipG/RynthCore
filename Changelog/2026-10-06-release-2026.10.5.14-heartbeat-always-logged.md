# RynthCore 2026.10.5.14 — engine heartbeat is always logged

**Date:** 2026-10-06
**Branch:** `fix/heartbeat-always-logged` (from `main` 143eaa9); deployed build is the
same fix cherry-picked onto `fix/restore-sk-features` (the 2026.10.5.13 line)
**Previous release:** 2026.10.5.13 (895a63a)
**Component:** `RynthCore.Engine` only (no plugin API change)

## Problem

The launcher killed healthy, in-world clients and relaunched them every few minutes
(Silentkelpie and Silentstorm, 2026-10-06 14:46 to 15:13; launcher log lines
`WEDGE: PID … killed - engine heartbeat silent for >120s while process alive`).

- The launcher's wedge watchdog treats `RynthCore.<pid>.log` not being written for
  120 s as a dead engine and kills the process.
- The engine's once-a-second heartbeat line (`hb #N … fps= … login= …`) was written
  through `RynthLog.Info`, which writes at the **General category's** level.
- With `LoggingLevel = Info` and `General = Trace` (launcher logging settings), the
  heartbeat was emitted at Trace and filtered out by the global Info threshold, so the
  log went quiet once a character was in-world and the watchdog fired.
- The launcher copies its own `LoggingLevel` into `engine.json` on every launch, so a
  hand edit of `engine.json` only lasted until the next relaunch.
- Knock-on effect: relaunches landed while the killed character was still logged in on
  the server, and the new client was booted to the end-of-session screen
  (`LogOffCharacter(immediate=1)` from `gmEpilogueUI`) about 35 s after launch.

## Fix

- New `RynthLog.Heartbeat(string)`: writes unconditionally (every `LoggingLevel`,
  including Off), tagged `[INF]`, like `RynthLog.Error` does for errors.
- `HeartbeatLogger` writes the `hb #` line through `RynthLog.Heartbeat`.
- No change to the line format, so every launcher's `WedgeHbRegex` still parses it.

## Notes

- The startup warning about categories above the global level stays; it still applies
  to every other line.
- Workaround for older engines: set the launcher's global logging level to Trace, or
  turn off auto-restart of wedged clients.

## Files

- `src/RynthCore.Engine/RynthLog.cs` — `Heartbeat` method.
- `src/RynthCore.Engine/Compatibility/HeartbeatLogger.cs` — heartbeat uses it.

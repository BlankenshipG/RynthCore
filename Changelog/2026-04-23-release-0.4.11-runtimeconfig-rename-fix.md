# RynthBundle 0.4.11

Date: 2026-04-23

## Summary

Fix launcher runtime detection so an installed .NET 10 runtime is correctly used instead of repeatedly showing a runtime-install prompt.

## Root Cause

The installer staging step renamed `RynthCore.App.Avalonia.exe` to `RynthCore.exe`, but did not rename:

- `RynthCore.App.Avalonia.runtimeconfig.json`
- `RynthCore.App.Avalonia.deps.json`

That mismatch can break host runtime resolution for the renamed apphost.

## Fix

Updated `installer/Build-Installer.ps1` so staging now renames launcher host metadata with the apphost:

- `RynthCore.App.Avalonia.runtimeconfig.json` -> `RynthCore.runtimeconfig.json`
- `RynthCore.App.Avalonia.deps.json` -> `RynthCore.deps.json`

## Build Stamp

- `RynthCore.Engine` build stamp: `2026-04-23-v61-bundle-0411-runtime-detection-fix`

## Build

- `Build-Installer.ps1 -Version 0.4.11`
- Output: `installer/Output/RynthBundle-Setup-0.4.11.exe`

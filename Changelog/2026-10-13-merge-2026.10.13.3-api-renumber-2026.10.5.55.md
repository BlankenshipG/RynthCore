# 2026.10.5.55 - rynth snapshot 2026.10.13.3 merged, plugin API v86

Previous release: 2026.10.5.54.

Goes with RynthSuite's `Changelog/2026-10-13-merge-2026.10.13.3-api-renumber.md`:
RynthAi 0.5.63-legacy-ui, RynthOracle 0.2.6, ub-Rythai 3.1.14, RynthJuice 0.1.3
and the 16 server plugins at 0.1.3. Install them with this engine.

## Problem

rynth's snapshot 2026.10.13.3 made plugin API v84 `GetObjectProperties`. This
build had already used v84 for `ArmConfirmation` / `GetLastConfirmation` and
v85 for `GetServerStateJson`, so the same version number meant different
tables.

## Change

- Merged snapshot 2026.10.13.3:
  - `GetObjectProperties` (ObjectPropertyRecord, ObjectPropertyDump,
    PropertyWire)
  - the SDK's `ObjectProperties`
  - `tools/ObjectPropertyTests`
- Our table entries now follow upstream's:
  - v84: `GetObjectPropertiesFn` (upstream)
  - v85: `ArmConfirmationFn`, `GetLastConfirmationFn`
  - v86: `GetServerStateJsonFn`
- `PluginContractVersion.Current` and `RynthCoreSdkApiVersion` are now 86.
- In the SDK, `HasConfirmationAnswers` now needs v85+ and
  `HasGetServerStateJson` v86+.
- Plugins built against the 2026.10.5.54 layout (v85) must be rebuilt.

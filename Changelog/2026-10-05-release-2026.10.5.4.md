## Summary

A third test build of the aelrynth 2026.10.5.1 merge. Details:
`2026-10-05-rynthai-launcher-remote-commands.md`.

## Fixes

- **Char / Hub dashboard buttons** open their windows. 2026.10.5.3 showed the buttons, but RynthAi
  threw away the commands they send. The aelrynth merge had dropped `hub` / `huds` / `remote` from
  RynthAi's remote-command switch.
  - Char opens the ILT Hub (`/ra hub show`).
  - Hub: left-click toggles the Mini Remote (`/ra remote toggle`); right-click opens Inventory HUDs (`/ra huds show`).
- RynthAi logs an unknown remote command as `ignored`, not `applied`.
- RynthAi plugin version is 0.5.2-legacy-ui (previous: 0.5.1-legacy-ui).

## Still open

- No Decal bridge in this build (Decal 3.0 is not installed on the build machine).
- Several new upstream paths are hard-coded to `C:\Games\...`.
- The ImGui Items view has no Shields section yet.
- RynthAi's 0.6.33 augmentation clamp fix is still stashed on SK-local.

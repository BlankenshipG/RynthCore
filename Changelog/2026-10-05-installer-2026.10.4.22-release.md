## Changes

- **Chat auto-translation** (RynthAi 0.6.32).
  - **Incoming:** chat on the channels you tick is translated into your receive language and
    written back to AC chat and RynthChat as `[Translate] [Channel] Name (lang): text`.
  - **Outgoing:** lines you type on the ticked channels are translated into your send language
    before they go out. Start a line with `\` to send it untranslated.
  - **Channels:** all 14 (Local, Tell, Fellowship, the allegiance channels, General, Trade,
    LFG, Roleplay, Society, Olthoi) can be ticked for listen and send separately.
  - **Services:** Google Cloud Translation (default), DeepL or LibreTranslate.
  - **Where to find it:**
    - Chat Translate window: `/ra translate window`
    - Settings: Advanced Settings > Translate, which includes the default send language
    - Mini Remote: a new row for the receive and send languages, with a swap button
  - See `2026-10-05-chat-translation.md`.

## Upgrade notes

- **Setup:** translation is off until you add an API key (Settings tab or Advanced Settings >
  Translate) and tick Enabled. Outgoing translation also has its own switch, and is off by
  default.
- **Settings file:** settings are shared by all characters in `RynthAi\translate.json`. The API
  key is stored there in plain text.
- **Fonts:** AC's chat font can't draw CJK, Thai or Arabic script, so translations into those
  languages show as boxes in chat.
- **Advanced Settings:** "Translate" was added just above "Diagnostics" in the page list. If
  the window was left on Diagnostics, it opens on Translate once.

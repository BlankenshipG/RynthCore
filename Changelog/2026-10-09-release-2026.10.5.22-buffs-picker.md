# RynthCore 2026.10.5.22: Buffs picker in Loaded Files

Released 2026-10-09. Previous release: 2026.10.5.21 (Mini Remote drawer).
Pairs with RynthAi 0.5.31-legacy-ui.

## What's new

- **Buffs picker.** The RynthAi dashboard's loaded files (the docked Loaded files drawer, and
  the header of a popped-out dashboard) have a fifth row, **Buffs:**, under Meta. It lists
  "Built-in" (buffing's own list) and every buff profile in `RynthAi\BuffProfiles`; picking one
  makes buffing use it.
- **Spells button.** A sparkle button at the end of the Buffs row opens or closes RynthAi's
  Spells window, where buff profiles are built.
- **Settings > Buffing** has a "Buff Profiles: Spells..." button that opens the same window.
- The Loaded files tooltips (drawer tab, popped-out caret) list the Buffs choice too.

## Compatibility

- With a RynthAi older than 0.5.31 the snapshot has no buff profiles: the row shows "Built-in"
  and its picker has nothing to choose; the Spells button does nothing (the plugin logs an unknown
  remote command).

## Files

- `UI/Data/RynthAiData.cs`: `RynthAiSnapshot.BuffProfiles` / `CurrentBuffName` /
  `SelectedBuffIdx`; `RynthAiView.BuffText`.
- `ImGui/Panels/RynthAiFace.cs`: fifth selector slot (picker kind 4), the Buffs row in the
  header grid, the Spells button option on `Selector`, caret tooltip.
- `ImGui/Panels/RynthAiFace.Drawers.cs`: the Buffs row and height in `FilesDrawer`, tab tooltip.
- `UI/Data/SettingsData.cs`: Buffing > Buff Profiles button (`spells show`).

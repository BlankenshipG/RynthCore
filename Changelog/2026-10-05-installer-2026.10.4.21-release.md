## Changes

- **Pet refill loop fix** (RynthAi 0.6.28 + engine). SilentStorm kept re-using Encapsulated
  Spirits on a full essence, because the engine served a stale empty charge count. Property
  updates now patch the appraisal cache, and the plugin trusts the server's "full" reply and
  parks an essence after repeated refills. See `2026-10-04-pet-refill-loop-fix.md`.
- **Item info on click** (RynthAi 0.6.29). Optionally print weapon and armour info to chat on a
  left or right click, in the same multi-line layout as pets. See
  `2026-10-04-item-info-click-and-pet-layout.md`.
- **Nav editor, waypoint overlay and breadcrumbs** (RynthAi 0.6.30).
  - **Editor:** UB-IT-style editing (insert above/below, multi-select, duplicate, reverse, snap
    to path, pause / chat / recall / portal steps, Save As), plus route recording with portal
    capture and a Simplify tool.
  - **Overlay:** a Nav HUD (distance, direction arrow, next step), step labels and a guide line.
  - **Breadcrumbs:** a trail you can turn into a route or a backtrack route.
  - **Height fix:** waypoints added from the UI, `/ra addnavpt` and the bridge were saved at
    the wrong height; a repair tool fixes saved routes.
  - See `2026-10-04-nav-editor-overlay-breadcrumbs.md`.
- **Mini Remote target and summon** (RynthAi 0.6.31). The Mini Remote shows the creature combat
  is attacking (name, distance, health bar) and your summon's health and time left. See
  `2026-10-05-mini-remote-target-and-summon.md`.
- **Chat standard filters** (engine).
  - **Standard filters:** the Chat Filters window has a page of 38 canned UB-IT-style filters
    (combat, casting, items, social, NPC, pets). Tick one to hide those lines, or name a tab to
    move them there.
  - **Custom rules:** now support plain-text Contains / Starts with / Ends with as well as regex.
  - **Line tester:** shows which filter catches a pasted line.
  - See `2026-10-05-chat-standard-filters.md`.

## Upgrade notes

- **Settings:** existing chat filter rules load unchanged (they stay in Regex mode). All
  standard filters start off.
- **Mini Remote polling:** while it is open, the Mini Remote polls the summon's health every
  3 s and re-queries the combat target afterwards. If mobs start getting blacklisted while
  the summon row is showing, report it.
- **Logging:** `engine.json` may still be at `Trace` from earlier debugging; set it back to
  `Info` in the launcher.

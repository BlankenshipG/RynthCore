# Release notes — RynthBundle **0.4.2** (2026-04-23)

## Installer

- **Primary output:** `installer\Output\RynthBundle-Setup-0.4.2.exe` (when `-Version 0.4.2` is passed, `Build-Installer.ps1` sets Inno **`OutputBaseFilename`** to a versioned name so the compile succeeds even if `RynthBundle-Setup.exe` is locked by another process).
- **Canonical copy:** the script **best-effort** copies that file to `installer\Output\RynthBundle-Setup.exe` when possible (skip if the destination is open).
- **App version (Inno Setup):** `0.4.2` (pass `-Version 0.4.2` to `Build-Release-All.ps1` / `Build-Installer.ps1`).
- **Pipeline:** `RynthCore.sln` **Release**, then publish (launcher self-contained x86, engine NativeAOT x86, injector x86, **RynthSuite** `Plugins\RynthCore.Plugin.*`, **ub-Rythai** `RynthCore.Plugin.UbRythai` when the sibling `ub-Rythai` repo is present, LootEditor + MonsterEditor x64), staging, Inno Setup.

## Highlights in this bundle

### ub-Rythai (Utility Belt–style RynthCore plugin)

- **`installer\Build-Installer.ps1`** now discovers **`..\ub-Rythai\RynthCore.Plugin.UbRythai\RynthCore.Plugin.UbRythai.csproj`** (same parent folder as `RynthCore` and `RynthSuite`), publishes it with the other NativeAOT plugins, and stages **`RynthCore.Plugin.UbRythai.dll`** into **`Runtime\Plugins\`**.
- **`-SkipUbRythai`** omits that step (for environments without the checkout). **`-UbRythaiPluginProject`** overrides the project path.
- Plugin assembly version for this release line: **3.1.8** (`ub-Rythai/RynthCore.Plugin.UbRythai/RynthCore.Plugin.UbRythai.csproj`).

### RynthCore engine

- **Build stamp:** `2026-04-22-v57-plugin-extra-path-dedupe` — skips duplicate extra plugin paths that would re-stage the same DLL name and break hot reload; clears export delegates before `FreeLibrary` on unload. See `Changelog/2026-04-22-plugin-extra-path-dedupe-hot-reload.md`.

## Build command used

```powershell
cd <RynthCore repo root>
.\Build-Release-All.ps1 -Version 0.4.2
```

With a non-default RynthSuite or ub-Rythai layout:

```powershell
.\Build-Release-All.ps1 -Version 0.4.2 -RynthSuiteRoot "D:\src\RynthSuite" -UbRythaiPluginProject "D:\src\ub-Rythai\RynthCore.Plugin.UbRythai\RynthCore.Plugin.UbRythai.csproj"
```
